# Marketplace Agrícola

Plataforma web que conecta a pequeños productores agrícolas de Loja con compradores finales, sin intermediarios. Proyecto del curso Ingeniería de Software (LTI_05A_INS) de la UIDE, Campus Loja.

## Contenido del repositorio

- `docs/vision-producto.md`: visión con la plantilla de Moore.
- `docs/mapa-stakeholders.md`: matriz de influencia e interés.
- `docs/srs.md`: requisitos funcionales y no funcionales.
- `docs/backlog.md`: historias priorizadas con MoSCoW.
- `docs/criterios-aceptacion.md`: criterios de las historias del sprint 1.
- `docs/plan-sprint-1.md`: objetivo, capacidad y tareas del sprint 1.

## Flujo de trabajo

1. Rama corta desde `main`, de un día y dos como máximo.
2. Commits pequeños y en español.
3. Pull request de hasta 200 líneas y un solo tema.
4. Lo revisa otra persona. Si toca login o datos de usuarios, hacen falta dos aprobaciones.
5. Merge a `main` con la tubería en verde y etiqueta cuando cierra el sprint.

## Cómo ejecutarlo

Todavía no hay código. El sprint 1 construye el registro, la publicación de productos y el catálogo. Las instrucciones de ejecución se agregarán aquí cuando exista la primera versión.
